# 独立 Python 项目架构

当前 Python 核心、CLI、HTTP、SQLite、资源解析、NBT 适配和 Three.js GUI 已实现；MCP、截图任务与模型驱动属于 P6/P7，尚未实现。阶段安排以 [实施路线](ROADMAP.md) 为准。

## 技术选择

采用 Python 为核心的单体应用，按功能与职责模块化。无需微服务、消息队列或复杂插件体系。

| 部分 | 已选技术 / 后续计划 | 目的 |
| --- | --- | --- |
| 核心语言 | Python 3.12+，最初以 3.12 验证 | 场景、事务、规则、资产与 AI 工具 |
| 包与环境 | `pyproject.toml`、`src` 布局、uv 锁文件 | 独立安装与可重复环境 |
| 数据边界 | Pydantic 2 | 配置、CLI/API/MCP 输入输出；领域对象不依赖传输模型 |
| CLI | Typer | 人与自动化脚本操作入口 |
| 本地服务 | FastAPI | 浏览器与 Python 应用服务通信 |
| 项目存储 | SQLite + 分块场景与编辑日志 | 事务、恢复、增量保存和历史 |
| NBT | nbtlib；独立 litemapy 仅用于验收 | `.litematic` 读写，长整数与标签类型保留 |
| 三维界面 | TypeScript + Three.js，轻量界面组件 | WebGL、拾取、选择、相机和实时编辑 |
| AI 接入（未实现） | 独立 MCP 适配器及图像反馈 | P6 外部客户端，P7 自动模型驱动 |

Python 核心不意味着浏览器三维渲染也由 Python 执行。网页三维部分必须有浏览器端代码；它负责显示与交互，不保存另一套权威建筑数据。Node.js 可以用于前端构建，不应成为已打包 Python 平台的运行前提。

首版采用本地浏览器 UI。当前没有要求全 Python 源码或原生桌面窗口，暂不增加桌面 GUI 框架。

## 依赖规则

- `domain` 不导入 FastAPI、MCP、数据库、浏览器或模型 SDK。
- `application` 使用领域逻辑和少量明确接口；不访问旧项目的内部模块。
- `adapters` 实现持久化、格式与资源接口，外部格式不会成为编辑规则的内部数据模型。
- CLI、HTTP 与 MCP 调用相同应用服务；禁止三种入口各写一遍编辑流程。
- `bootstrap` 负责组装实现。依赖方向由静态检查与导入测试验证。
- 前端以服务端修订为准，提交选区和操作；服务端验证并返回确定差异。
- 与未来 bot 只通过已导出资产或公开格式交互，本项目不认识施工器、库存、寻路或角色权限。

## 场景与持久化

场景使用整数局部坐标、规范方块名和完整属性集合；物品 ID 与方块状态分开。版本数字 ID 不能跨版本当作稳定语义身份。

采用分块空间索引。分块大小初始可用 16×16×16，通过基准确认。每块内部使用局部调色板与压缩状态数据，细节隐藏在存储适配器之后；大量方块不作为逐格大 JSON 在每次编辑中往返传输。

SQLite 保存项目元数据、分块内容、修订、编辑差异与历史。一个编辑事务同时提交状态和日志；失败整体回滚，成功返回新修订。支持 `expected_revision` 防止旧稿覆盖和 `request_id` 避免客户端重试重复修改。

重做与撤销为新的可审查状态变更，修订号不回退；事务竞争、异常退出和迁移失败已测试。长期候选稿与模型任务记录待 P7；当前持久化的是编辑历史。

用户项目、资源缓存、配置、日志与导出产物放在可配置的数据目录，不放入 Python 安装包。支持便携路径；禁止写死旧仓库、用户名和 Codex 安装路径。

## 资源与材料

资源包清单关联 MC 版本、注册表来源、资源来源和哈希。先校验版本一致，再生成缓存；同名方块不自动说明属性与模型兼容。

查询返回分页、准确总数、块名、中文/英文显示名、合法属性、缩略图和覆盖状态。状态标记区分：可静态渲染、需要专用渲染、不可见、缺资料。设计可表达能力、预览能力与游戏导出能力分别记录。

首版全量目录来自经过核对的 1.20.1 数据，不手写材料白名单。特殊方块模型、动态内容与连接形状有独立适配，不用普通立方体掩盖缺口。

旧原型已有网站渲染资料和具体建筑的成功预览，新实现复用解析经验与可核对样例。资源经过独立导入与版本核对后使用，原型目录和兼容别名不直接充当新项目全版本资源保证。

## 编辑与渲染

编辑基本操作与选区协议先稳定，然后增添镜像、阵列、挤出和曲线等组合工具。参数构件生成的结果仍可在逐格层编辑。

前端按分块更新网格，采用遮挡面裁剪及可复用几何；透明块与特殊模型单独处理。准确性先于只渲染彩色方块的性能演示。

当前浏览器验收脚本可生成实际 PNG，但还没有产品截图 API。P6 将实现固定修订的截图服务，返回 PNG、修订、相机和剖切信息；与 GUI 共用渲染器，管理浏览器依赖、超时、取消及失败结果。

## AI 工具契约

拟提供 `catalog.search`、`scene.inspect`、`scene.preview_edit`、`scene.commit_edit`、`history.undo/redo`、`render.views`、`asset.import/export`。

工具只返回必要的摘要、差异、资源引用和图片，不每次输出全部方块。修改有预算、显式选区、修订校验和原子性；错误包含具体路径与原因。AI 在合法工具内自由组合建筑，不需要执行任意 Python 源码才能使用平台。

接入 MCP 后，外部 AI 客户端即可使用工具；平台自行调用模型的自动设计循环属于后续模块。首版不绑定某个模型供应商。
