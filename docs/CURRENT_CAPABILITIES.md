## 实际验收

- Windows：36 项 pytest，包括真实 Chrome 与官方资源；strict mypy、Ruff、前端 TS/Prettier/build 通过。
- Linux：WSL Ubuntu 核心、类型、lint、构建与干净 wheel 安装；GitHub Actions Ubuntu 另通过实际官方资源与真实浏览器测试。
- 扩展浏览器：木屋起稿、改屋顶、调窗、放置、撤销重做、保存重开和导出；高级工具逐项操作及属性/选区/对比。
- 教堂：36,094 格、62 分块；导入、1,000 格编辑、撤销、剖切、相机、保存、导出与 720px 布局通过。
- 独立读取器：木屋和教堂全部状态/坐标一致，教堂 67 个方块实体和区域 NBT 保留；独立负尺寸、多区域、特殊空气删除和跨区域移动样例通过。
- 2026-10-10 优化回归：Windows 63 项通过、1 项文件替换因平台锁机制跳过；Linux 54 项核心通过。两平台类型、lint、wheel 构建与干净环境安装通过，前端 TS/Prettier 检查通过。该记录不替代最终大场景测量。
- 渲染优化：100,000格混合场景每帧调用29,596→243、旋转帧间隔P95 183.4→16.8ms；105,102格真实城堡裁片约16.8–16.9ms。普通画布DPR1/DPR2重复、宽视图、连续GUI交互与全量几何/状态核对通过；新增透明复用、遮挡失效和字牌生命周期验证后，6项相关浏览器回归通过。首次导入、比较等待、偶发约50ms帧和严格像素未通过均保留。完整百万格城堡全景约30FPS，未达到60FPS，未测百万格编辑。

机器、命令、性能值、截图与限制见 [P5 验收记录](P5_ACCEPTANCE.md) 和 [资源兼容范围](RESOURCES_AND_LIMITS.md)。单次局部基准不等于所有机器或更大建筑的性能保证。

P6 最终回归：Windows 82 项通过、1 项原有 SQLite 文件替换锁跳过；WSL Ubuntu 63 项核心通过，两平台类型/lint 与干净 wheel 的 gui/ai/render extras 安装通过。真实 stdio MCP、PNG ImageContent、HTTP 下载与 CLI 外部编辑刷新通过。实际 AI 木屋看图改稿后 870 格独立回读一致；100,000 格三视角截图约 5.8 秒。Linux 本轮未运行真实浏览器；受网络超时影响，本机 Playwright 管理的 Chromium 尚未安装，实际图像验证使用已安装 Chrome。完整证据见 [P6 验收](P6_ACCEPTANCE.md)。

## 旧原型的关系

旧 JS 原型位于 ai-mod 的 tools/design-workbench，曾使用网站预览资料显示小屋和教堂。它只提供解析经验与只读样例参考。新项目的 Python 核心不调用旧 Node.js 实现，实际资源独立来自官方 1.20.1 客户端，样例和项目已放入新目录。旧世界与代码未修改。
