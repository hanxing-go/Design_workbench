# 不同设备的页面外观

首页与赞助页的钻石、绿宝石、钻石镐、书、火把、地图和门使用本机导入的 Minecraft 官方贴图。草方块、工作台与箱子图标由原版贴图投影生成；赞助宝箱使用原版箱子贴图，支持悬停开盖、点击保持打开、键盘操作和减少动态效果偏好。首页建筑主要材料也使用原版贴图。源码中的简化 SVG 与程序纹理仅作为素材不可用时的回退。

方块图标采用原版物品栏的 30° 俯视、45° 水平视角，保留原始 16×16 方块贴图；草方块使用原版物品栏颜色 `#7cbd6b`。宝箱分别使用外盖、内盖、正面、右侧与独立锁扣贴图，保留官方模型的箱盖与底座比例。锁扣随箱盖转动，操作说明放在按钮的悬浮提示中，不覆盖箱体。

“我的设计”按需读取实际项目生成建筑缩略图，并按项目修订缓存；不会为每张卡片持续运行三维动画。卡片展示方块数、游戏版本与最近一次编辑时间。页面支持钻石镐光标，输入区域保留文字光标，画布保留拖动反馈。版本发现只检查安装元数据，不会为展示版本列表升级全部资源包。

本轮可重复的只读浏览器检查：`python scripts/ui_polish_smoke.py`（需 Chrome、Playwright 和运行于 8766 端口的本地工作台，并至少有一个非空项目）。检查结果与桌面、手机及宝箱开合截图输出至 `artifacts/ui-polish/`。

游戏素材位于配置的 `cache_dir/resources/`，不进入 Git。仅拉取源码、安装依赖与构建前端，并不会复制另一台设备的素材。在项目根目录执行：

```powershell
uv run --extra gui design-workbench resources setup --config config.example.toml
```

确认启动服务时也使用相同配置。素材就绪后，`/api/ui/sprites/diamond.png` 应返回 PNG。页面会在图标请求失败后有限重试，并在重新切回浏览器窗口或恢复网络时重试尚未加载的图标，无需一直保留简化版本。

页面布局按 CSS 像素计算，截图则可能按屏幕物理像素保存。Windows 显示缩放、浏览器缩放和浏览器工具栏都会影响截图里的内容大小与可见范围。对比时先用 `Ctrl+0` 恢复浏览器 100% 缩放，再使用相同的 CSS 视口尺寸；不要为抵消某台设备的系统缩放而全局缩小网页。

以赞助页为例，1888 × 944 CSS 像素下，页头约 92 像素高，首屏介绍区约 497 像素高，内容最大宽度为 1400 像素。设备像素比为 1.5 时，截图中的物理尺寸会相应变成 1.5 倍，实际 CSS 布局规则没有改变。

修改前端后还需执行 `npm.cmd run build --prefix frontend`。Python 服务提供 `src/design_workbench/static/` 中的构建产物，不直接提供 `frontend/src/` 中的源码。
