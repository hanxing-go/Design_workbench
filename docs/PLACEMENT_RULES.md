# 自动放置、形态选择与显示范围

点击放置默认按命中面、点击高度和相机方向选择方块状态。鼠标与第一人称放置共用后端 `place` 操作，不再直接写入默认方块状态。

## 放置规则

- 铁栅栏、不同颜色玻璃片、栅栏、栅栏门和围墙按邻接更新连接；楼梯计算直线、内角和外角。新增、删除、替换、复制与阵列都会更新受影响的局部邻居。
- 普通／陷阱箱在方向一致时配成双箱，最多两个；删除其中一个后恢复单箱。末影箱不会配对。
- 火把、普通/悬挂告示牌、旗帜、头颅和珊瑚扇根据点击面选择地面或墙面形态；梯子、按钮、拉杆、砂轮、钟等推断附着方向。需要支撑面却没有支撑时，点击放置会给出具体错误。
- 半砖根据点击高度与顶面/底面选择上下半部；点击同材质半砖的空半部可补成双层。不同材质不能在同格混合成双层。
- 门、床与双层植物完整生成；空间不足或任一部件越界时整次编辑失败。删除与替换会处理对应部件；变换要求选中完整结构。
- 自动变化与用户操作保存为同一历史记录，撤销、重做和导出使用实际存储的状态。

楼梯形态、正放/倒放、方向与半砖类型可通过材料面板中的图案选择，并显示当前形态预览。选择图案或修改高级属性会取消“自动朝向与贴合”，本次按手动属性放置。重新勾选即可恢复自动推断。

手动形态不是永久锁定：以后对附近方块进行自动编辑时，连接与楼梯拐角仍可更新。手动放置也会检查碰撞和结构完整性。

## 已有设计

导入不会自动改写原蓝图的状态。已有断开的连接或半个门可使用工具面板的“检查连接”查看建议，再预览并提交修复；被占用、越界或含受保护实体数据的位置不会强行补齐。

支撑方块被删除后，附着物保留，检查工具会提示支撑问题。工作台允许设计悬空结构，不执行生存模式的自动掉落、流体流动、红石更新或植物生长。

## API 与精确编辑

HTTP、CLI 和工具服务共用编辑契约。`place` 提供 `state`、`hit`、`normal`、相对命中位置 `location`、水平视角 `facing`、分组 `group` 和 `automatic`。默认编辑请求启用 `auto_connect` 与 `complete_structures`。

需要保留原始状态、故意制作不完整结构或外部工具精确写入时，使用 `set` 等原始操作，显式设置 `auto_connect: false` 和 `complete_structures: false`。这两个开关分别控制邻接更新与结构补全；导入路径默认保留原始状态。

## 专用预览

普通方块可以由模型 JSON 直接构建。头颅、箱子、旗帜、潜影盒等物品还需要专用几何与实体贴图；当前提供静态预览，素材缓存会按新的图集配方自动升级。

自定义玩家皮肤、旗帜图案、陶罐陶片图案等实体数据仍需额外实现显示；界面会说明预览限制，原始数据继续保留。没有实现的预览标为“暂无预览”，与“缺资源”分开显示。
