# UI 交互更新与 Minecraft 主题

## 首页入口

根路径展示 Minecraft 风格首页，沿用深色石灰面板、草绿配色、方形立体按钮和像素图标。首页包含独立新建设计、导入 `.litematic`、木屋快捷起稿、真实项目列表与名称搜索、网格/列表切换、建造指南和小贴士。首页访问本身不创建项目；编辑器左上角可返回首页，项目按本机最近打开顺序显示。

右侧 Three.js 浮空小岛使用本地程序绘制的像素材质，轮流展示林间木屋、石砖瞭望塔、樱花庭院、麦田风车、溪谷拱桥、紫晶祭坛与蒸汽飞艇。风车叶片缓慢转动，飞艇在空港上方轻轻浮动；保留树木、池塘、花朵、漂浮方块及木屋烟囱烟雾。建筑从第一种到第七种再倒序返回，来回循环，每轮搭建 8 秒、完整展示 10 秒、拆解 5 秒、切换留白 1 秒。动画可重播、暂停或手动切换建筑，支持拖动和方向键旋转；不可见与后台页面停止绘制与计时。减少动态效果模式保持完整建筑静止，仍可手动切换；WebGL 不可用时展示静态草方块。首页与编辑器按入口分开加载；`?project=...` 和 `?view=workbench` 直接进入编辑器。

首页与赞助页的钻石、绿宝石、铁镐、书和火把优先显示本地已安装 Minecraft 资源中的原版像素贴图，资源未就绪时保留自绘图标。赞助页使用原版钻石替代爱心。浮空小岛修正了材质重复条纹、门把手重复、横梁纹理方向、树叶覆盖树干和墙体、池塘与木屋重叠、花朵与茎脱离等绘制问题。

TypeScript、Prettier 与生产构建通过；真实 Chrome 端到端验证覆盖首页新建、项目搜索与切换、导入、木屋仅生成一次，以及原编辑器的编辑、历史、导出、播放、面板和窄屏流程。桌面与手机页面已截图检查。

## 功能检查点

先完成可单独回退的交互提交，再提交 Minecraft 主题；已有 `v0.1.0` 标签保持不动。

- 画布底部播放条：播放/暂停、0.5×/1×/2×/4×、拖动进度、逐层切换、层序号输入和显示全部。由最低 Y 向最高 Y 展示，到末层自动停止；操作、切换项目或后台页面时暂停。空场景和单层场景不会启动无意义的播放。
- 顶部重命名弹窗：空白校验、128 字符限制、自动保存、撤销/重做、幂等请求和修订冲突保护；列表和画布名称同步。
- 左右面板独立隐藏，记住本机偏好；专注模式恢复进入前的面板状态。窄屏默认隐藏侧栏，打开时覆盖画布。
- 教程按钮和快捷键说明；输入框、选择框、中文输入和弹窗中保留正常键盘操作。Tab 仅在画布或页面背景有焦点时切换专注模式。

层序号从 1 开始；Y 显示实际 Minecraft 坐标，支持负高度和包含空层的建筑。

功能检查点：`ab7b55d`。后续主题提交可独立回退到这一版。

## Minecraft 主题

深色石灰工作台、方形立体按钮、物品栏材料格、自绘草方块标志和绿色经验条风格的进度条。画布背景与网格读取 CSS 主题变量，方块材质、光照和编辑数据保持原有行为。

桌面进度条随画布延展；960px 以下独占一行，避免被按钮挤短。面板可独立收起；专注视图自动调整画布尺寸。教程和重命名弹窗采用同一主题，保留输入、焦点提示、关闭和键盘导航。

在独立工作树使用真实官方资源与 Chrome 执行：

- 35 项非浏览器/非资源测试通过，包括重命名持久化、方块保留、冲突、重复请求、撤销/重做和非法名称。
- Chrome 端到端工作流通过：生成木屋、替换、预览、撤销/重做、蓝图导出、逐层播放到末层、层号输入、负 Y、面板宽度与偏好、教程、快捷键、名称重开、390px 窄屏无横向溢出。
- Ruff、mypy、TypeScript、Prettier 和 Vite 构建通过，随包静态产物同步更新。
- 主题版本的全部 6 项资源/浏览器测试通过，包括特殊方块渲染回归；35 项核心测试已在功能版本通过。
- 在 1920、1440、1100、820、780、390px 六种宽度检查页面，无横向溢出，状态栏完整可见；检查完整视图、专注视图、教程和窄屏截图，浏览器无脚本错误。

浏览器测试使用临时项目目录，不修改用户的设计数据。工作树隔离同时进行的渲染性能优化。
